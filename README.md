# 콘서트 대비 일본어 노트

일본어를 처음 접하는 콘서트·팬미팅 관객을 위한 모바일 학습 앱입니다. 특정 아티스트나 팬덤에 한정하지 않고, 짧은 무대 멘트와 관객 지시를 이해하는 기초를 만듭니다. 한 달 안에 모든 콘서트 일본어를 습득하거나 실제 속도의 말을 이해할 수 있다고 보장하지 않습니다.

## 쉬운 30일 기본 과정

하루 새 문장 3개와 복습·비교 2단계로 진행하며, 새로 배우는 문장은 총 90개입니다. 한 문장마다 먼저 알아들을 핵심 단서 하나와 상황·행동을 보여 줍니다. 하루 단어 목표는 최대 3개입니다.

- 1~3단계: 짧은 새 문장과 핵심 단서
- 4단계: 전날 첫 문장의 뜻 떠올리기 (1일차는 방금 배운 인사)
- 5단계: 당일 배운 두 문장의 차이 비교하기
- 뜻과 비교 답은 먼저 떠올린 뒤 펼쳐서 확인합니다. 비교 단계에 새로운 문장을 추가하지 않습니다.
- 핵심 단어를 본 뒤 마치거나, 선택 확인 퀴즈로 오늘 새 문장 3개를 확인할 수 있습니다.

[30일 학습표](SYLLABUS.md), [입문 난도 조정과 문장 변경표](BEGINNER_CHANGES.md), [현재 비중과 한계](COVERAGE.md)를 확인할 수 있습니다. 이전의 150문장 과정 개편 이력은 [CURRICULUM_CHANGES.md](CURRICULUM_CHANGES.md)에 보관합니다.

이 과정은 실제 공연 대본을 재현한 것이 아닙니다. 일정·촬영·휴대전화·응원봉 규칙은 공연마다 다르며 실제 현장 공지와 직원 안내를 따릅니다.

## 학습 메뉴

1. 글자 첫걸음: 히라가나·가타카나, 소리 규칙, 공연 관련 예시와 루비 한자
2. 매일 공부해요: 하루 새 문장 3개·복습과 비교 2단계·최대 3개 핵심 단어
3. 문장으로 외워요: 인사·감사, 호응·곡 소개·진행, 소감·준비·팬에게 전하는 말, 공연 공지
4. 단어로 익혀요: 문장과 연결한 단어와 활용 예문
5. 퀴즈로 확인해요: 일본어·한글 읽는 법을 보고 한국어 뜻을 고르는 2지선다

전체 라이브러리는 문장 카드 335개·단어 카드 299개입니다. ‘기본부터’에서는 기본 90문장과 핵심 단어를, ‘심화·추가’에서는 긴 공지·상세 토크·추가 표현을 선택해서 봅니다. 동일한 인사 카드의 기존 중복이 있어 카드 수와 고유 문장 수는 다를 수 있습니다. 기존 문장은 삭제하지 않았습니다.

## 공연 공지

‘문장으로 외워요 → 공연 전·현장 공지’에서 기본·심화로 나눠 봅니다. 공지 36개 중 짧은 기본 공지는 14개이며, 나머지 22개는 심화·추가입니다. 모두 아티스트·MC 멘트와 구별해 ‘공연 공지’로 표시합니다. 「開場」(입장 시작)와 「開演」(공연 시작), 촬영 허용과 금지처럼 상황을 판단하는 말을 기본에서 먼저 익힙니다.

## 복습과 기록

완료·오답 기록은 현재 브라우저에만 보관하며 기기 간 동기화되지 않습니다. 저장소가 차단되어도 학습은 가능합니다. 쉬운 과정의 기록은 `concert-japanese-daily-v3`에 저장합니다. 이전 `concert-japanese-daily-v2`와 `aroha-daily-v1` 기록은 삭제하지 않으며, 바뀐 날짜에 이전 완료 표시를 적용하지 않습니다.

매일 확인 퀴즈는 선택 사항이고 당일 세 문장을 모두 확인합니다. 기본 퀴즈에는 기본 문장·단어만 나오며 심화 퀴즈는 별도로 선택합니다. 완료는 학습 진행 표시이며 숙달 판정이 아닙니다. 복습·비교는 장기 기억이나 실제 청취를 보장하지 않습니다.

## 자료와 음성

실제 아티스트의 발언·일정·개인 취향을 인용하거나 단정하지 않는 학습용 예문입니다. 기존 자료에서 출발한 예문과 이번에 작성한 범용 공연 표현을 함께 제공합니다. 특정 소재는 선택 예문으로만 사용합니다.

일본어 발음 음성은 아직 없습니다. 한글 읽는 법은 보조 수단이며 일본어 발음을 정확히 재현하지 않습니다. 정답·오답·버튼 소리는 Web Audio 효과음입니다. 실제 청취를 위한 음성 훈련은 별도 개선 과제입니다.

## 실행·검증·배포

이 폴더에서 `python3 -m http.server 8001 --bind 127.0.0.1`을 실행합니다. 별도 설치·빌드·비밀키는 필요하지 않습니다. Google Fonts는 선택 사항이며 기본 폰트로도 동작합니다.

데이터 연결·보기·필수 범위 검증: `node tests/curriculum.test.cjs`

GitHub Pages는 `main` 브랜치의 `/(root)`를 게시 소스로 사용합니다. 변경을 `main`에 푸시한 뒤 Actions의 Pages 배포 결과를 확인합니다.
