# AROHA Japanese Level Up!

일본어를 처음 접하는 아로하가 공연·라이브에서 아티스트의 말을 이해하도록 돕는 모바일 학습 앱입니다.

## 현재 구성

- 글자 첫걸음: 글자와 소리, 히라가나 46자, 가타카나 46자, 기본 소리 규칙
- 자주 쓰는 단어: 공연·라이브 관련 단어 12개
- 한자도 만나봐요: 따나퀴즈에서 가져온 루비 단어 12개와 펼쳐 보는 예문
- 단어로 배워요: 공연 예문에서 뽑은 단어 77개, 원문 펼치기와 문장 카드 이동
- 문장으로 배워요: 공연 전체를 반복하는 4개 묶음, 문장이 14 → 28 → 42 → 70개로 누적됩니다. 각 묶음에 첫인사부터 마지막 인사까지 포함되며 주차·주제별 진도 잠금은 없습니다.
- 단어 묶음도 해당 공연 문장에 맞춰 함께 늘어나며, 끝에서 처음부터 다시 볼 수 있습니다.
- 퀴즈로 확인해요: 일본어 단어·문장과 한글 읽는 법을 보고 한국어 뜻을 고르는 2지선다, 각 5문제
- 콘서트에 집중하며 라이브 메뉴는 제외했습니다. 홈은 글자 첫걸음 → 매일 공부해요 → 문장으로 외워요 → 단어로 익혀요 → 퀴즈로 확인해요 순서입니다.

공연 문장은 일반 학습용 예문과 따나노트의 정답·교정된 표현을 활용했습니다. 특정 아티스트의 실제 발언 그대로를 인용하거나 음성을 받아쓴 자료는 아닙니다. 단어 카드는 해당 예문에 나온 형태와 기본형을 연결합니다.

기존 따나퀴즈는 수정하지 않았으며, 기존 Git 이력을 복사하지 않았습니다. 학습 내용은 검토용 초안입니다.

## 실행

이 폴더에서 `python3 -m http.server 8001 --bind 127.0.0.1`을 실행합니다. 별도 빌드·패키지·비밀키가 필요하지 않습니다. Google Fonts는 선택 사항이며 기본 폰트로도 동작합니다.

## GitHub Pages 배포

저장소: `ddanalover/aroha-japanese-levelup`

1. 이 폴더의 파일을 저장소 루트에 올립니다. index.html과 app.js는 루트에, lessons.js와 kanji.js는 data 폴더에 있어야 합니다.
2. Settings → Pages → Build and deployment에서 Source를 Deploy from a branch로 설정합니다.
3. Branch는 main, Folder는 /(root)로 설정하고 Save를 누릅니다.
4. Actions의 Pages 배포가 성공하면 Settings → Pages에서 제공하는 주소를 엽니다.

배포 예상 주소: https://ddanalover.github.io/aroha-japanese-levelup/
(배포 성공 전에는 사용할 수 없습니다.)

외부 API, 계정 가입, 사용자 데이터 수집 기능은 없습니다.

## 매일 공부해요

합의한 첫 25문장으로 1~5일차를 구성했습니다. 6~30일차는 내용을 정한 후 채우며, 현재는 ‘내용 준비 중’으로 표시됩니다. 준비된 날짜는 진도와 상관없이 자유롭게 열 수 있습니다.

하루 흐름은 새 문장 5개 → 해당 문장의 단어·표현 → 전날 문장 복습 3문제입니다. 1일차에는 복습이 없습니다. 이후 7일차부터는 전날 2개 + 더 이전 날짜 1개를 우선 복습하고, 틀린 문장을 우선 선택하도록 준비했습니다. 단어와 문장 모두 일본어를 보고 한국어 뜻을 고르는 방식이며, 한글 읽는 법을 아래에 표시합니다.

완료 날짜와 복습 오답은 현재 브라우저의 로컬 저장소에만 보관합니다. 다른 기기와 동기화되지 않으며, 저장소가 차단된 환경에서도 학습은 계속할 수 있습니다.

## 퀴즈 화면과 보기

따나퀴즈의 문제 카드, STEP 표시와 진행 바, 정오답 해설 팝업, 결과 리포트, 다시 하기/계속 풀기 흐름을 사용합니다. 일일 복습도 같은 화면을 사용하며 3문제 기준으로 결과를 표시합니다.

보기는 무작위로 다른 주제를 가져오지 않습니다. `data/quiz-options.js`에 문항별로 같은 주제의 다른 뜻을 짝지어 두었습니다. 예: 嬉しい → 기쁘다 / 슬프다, 次 → 다음 / 이전. 새 문장·단어를 추가할 때는 이 파일에도 해당 보기를 추가해야 합니다. 보기의 위치만 섞습니다.

버튼·정답·오답 효과음은 원본과 같은 Web Audio 파형·주파수·길이로 합성하며, 사용자 조작 시 오디오를 시작합니다. 오디오를 사용할 수 없는 환경에서도 학습은 계속됩니다.

## 운동 토크

콘서트 토크에서 관심사를 이야기하는 학습용 예문 11개와 연결 단어 20개를 추가했습니다. 筋トレ・筋肉・ムキムキ・トレーニング・ランニング・筋肉痛 등을 다룹니다. 실제 아티스트 발언 인용이나 운동 방법 안내가 아닙니다. 운동 표현도 별도의 진도 단원이 아니라 같은 공연 흐름의 토크 안에서 만납니다. 각 단어·문항의 한국어 보기는 운동·몸 상태와 관련된 뜻끼리 짝지었습니다.

현재 전체 자료는 문장 70개·단어 77개입니다. 매일 공부해요의 1~5일차(합의한 25문장)는 그대로 유지했습니다.
