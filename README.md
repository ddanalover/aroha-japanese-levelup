# AROHA Japanese Level Up!

일본어를 처음 접하는 아로하가 콘서트의 흐름과 아티스트의 멘트를 이해하도록 돕는 모바일 학습 앱입니다. 기존 따나퀴즈는 그대로 유지하고 별도 앱으로 구성했습니다.

## 홈 구성

1. 글자 첫걸음: 히라가나·가타카나 기본 글자, 소리 규칙, 공연 관련 단어와 루비 한자
2. 매일 공부해요: 30일 × 매일 5문장, 총 150문장
3. 문장으로 외워요: 인사·감사·함께하자는 말 / 호응·곡 소개·코너 진행 / 소감·연습 이야기·팬에게 전하는 마음으로 분류
4. 단어로 익혀요: 문장과 동일한 세 가지 내용별 분류, 해당 분류의 원문으로 이동
5. 퀴즈로 확인해요: 일본어와 한글 읽는 법을 보고 한국어 뜻을 고르는 2지선다

전체 라이브러리는 문장 252개·단어 245개입니다. 이 중 150개 문장을 날짜별로 중복 없이 배치했습니다. 매일의 문장·단어 목록은 [SYLLABUS.md](SYLLABUS.md)에서 확인할 수 있습니다.

## 매일 공부해요

문장 5개를 통째로 익힌 뒤, 그 문장에 나온 단어·표현을 모아 보고 복습합니다. 인사만 배우는 주차처럼 나누지 않고, 여러 공연 순간을 매일 섞어 반복합니다. 근육·트레이닝·러닝 이야기도 공연 토크에 포함했습니다. 스크린 안내처럼 우선순위가 낮은 문장은 제외했습니다.

- 1일차: 새 문장 5개와 단어·표현, 복습 없음
- 2~6일차: 새 문장 5개와 전날 문장 복습 3문제
- 7~30일차: 새 문장 5개와 전날 문장 2문제 + 더 이전 문장 1문제
- 복습에서 틀린 문장을 우선 다시 선택
- 날짜·진도 잠금 없이 30일 모두 열기 가능

완료 날짜와 오답 기록은 현재 브라우저의 로컬 저장소에만 보관합니다. 다른 기기와 동기화되지 않으며 저장소가 차단되어도 학습할 수 있습니다. 기존 학습 기록을 초기화하지 않습니다.

## 자료와 음성

내용은 보편적인 공연 멘트 예문과 따나노트의 정답·교정된 표현을 활용한 학습용 초안입니다. 실제 아티스트 발언 그대로의 인용이나 받아쓰기로 표시하지 않습니다. 오답이나 문법 교정 자체를 가르치는 구성이 아닙니다.

음성 파일은 아직 포함하지 않았습니다. 지금은 문장·발음 안내·뜻·반복 복습의 틀을 제공하며, 향후 실제 음성을 바탕으로 자주 쓰는 말과 말투를 조정할 수 있습니다. 현재의 정답·오답·버튼 소리는 발음 음성이 아니라 Web Audio 효과음입니다.

## 퀴즈

따나퀴즈의 STEP 표시·진행 바·문제 카드·정오답 팝업·결과 리포트·다시 하기/계속 풀기 흐름을 사용합니다. 일반 퀴즈는 5문제, 일일 복습은 3문제입니다. 일본어 아래에 한글 읽는 법을 표시합니다.

한국어 보기는 `data/quiz-options.js`에서 문항별로 같은 범주의 다른 뜻을 직접 짝지었습니다. 예: 嬉しい → 기쁘다 / 슬프다, ランニング → 러닝·달리기 / 걷기. 보기의 위치만 섞습니다. 새 문장·단어를 추가할 때 이 파일에도 보기를 추가해야 합니다.

## 실행과 배포

이 폴더에서 `python3 -m http.server 8001 --bind 127.0.0.1`을 실행합니다. 별도 빌드·패키지·비밀키가 필요하지 않습니다. Google Fonts는 선택 사항이며 기본 폰트로도 동작합니다.

GitHub Pages는 `main` 브랜치의 `/(root)`를 게시 소스로 사용합니다. 변경을 `main`에 푸시한 후 Actions의 Pages 배포 성공을 확인합니다.

## 문장·단어 공통 분류

| 큰 분류 | 소분류 | 도달 목표 |
| --- | --- | --- |
| 인사·감사·함께하자는 말 | 만남과 인사 / 감사 / 함께하자는 말 | 익숙한 문장의 뜻을 바로 떠올리기 |
| 호응·곡 소개·코너 진행 | 관객 호응 / 곡·무대 소개 / MC 질문·게임 진행 | 관객에게 무엇을 부탁하는지 알기 |
| 소감·연습 이야기·팬에게 전하는 마음 | 기분과 소감 / 연습·운동 / 팬에게 전하는 마음 | 단어가 조금 달라져도 핵심 잡기 |

문장은 주된 용도로 분류하고 단어는 해당 분류의 원문에 연결합니다. 여러 내용에 함께 쓰이는 단어는 각 분류에서 다시 볼 수 있습니다. 같은 주차를 중복해서 완료해야 하거나 4주차를 별도로 열어야 하는 구조는 사용하지 않습니다. ‘매일 공부해요’의 30일·150문장, 복습 규칙과 기록은 유지합니다.

## MC와 공연 흐름

‘매일 공부해요’의 150문장은 아티스트 116개·MC 34개로 구성했습니다. 카드와 문장 퀴즈에 화자를 표시하며, 각 예문의 상황 설명으로 누구에게 하는 말인지 안내합니다. 1~5일차 입문 문장은 유지하고 6~30일차에서 MC 질문과 아티스트 답변을 연결합니다.

등장, 토크 질문, 게임 규칙·제한 시간·힌트·정답·재도전, 곡 감상 포인트, 관객 질문, 무대 전환, 앙코르, 마지막 메시지와 공연 종료 안내를 포함합니다. 첫 7일 안에 공연의 7개 큰 흐름이 모두 나옵니다. [COVERAGE.md](COVERAGE.md)에 범위와 남은 한계를 정리했습니다.

MC·아티스트 표시는 학습용 예문에서 맡은 역할이며 특정 음성을 분석해 확정한 화자 정보가 아닙니다.

## 소분류와 단어 활용 예문

문장·단어 모두 큰 분류 → 소분류 → 카드 순서로 이동합니다. 각 메뉴에 동일한 9개 소분류를 사용하며, 단어에서 문장으로 이동할 때도 해당 소분류의 원문을 엽니다. 카드의 ‘목록’은 소분류 목록으로, ‘큰 분류로’는 상위 목록으로 돌아갑니다.

‘매일 공부해요’ 1~30일차의 모든 단어 카드 아래에 그날의 다섯 문장 중 하나를 활용 예문으로 표시합니다. 일본어·루비·한글 읽는 법·한국어 뜻·화자를 함께 보여 줍니다. ‘단어로 익혀요’에서도 예문을 바로 볼 수 있고, 추가 원문은 펼쳐 볼 수 있습니다. 단어 퀴즈 정오답 팝업과 결과의 해설 복습에도 예문을 넣었습니다.

이미 합의한 문장을 예문으로 연결하며 새로운 문장이나 날짜별 학습 내용을 임의로 추가하지 않았습니다. 활용형과 표기 차이(みなさん/皆さん 등)를 고려해 문장에 단어를 연결합니다.

## 12월 공연 예상 주제와 설명 점검

겨울 날씨·새 앨범·커버곡·기타·홋카이도·연말의 예문 43개와 단어 46개를 보강했습니다. 매일 학습에서는 반복이 많은 27문장을 해당 대화로 교체했고, 30일·150문장과 1~5일차 입문 구성은 유지합니다. 모든 내용은 학습용 예문이며 실제 발언, 확정된 앨범·곡명·여행 일정으로 표시하지 않습니다.

일본어와 한국어가 붙어 읽기 어려운 설명 및 조사·뜻풀이를 정리했습니다. [LANGUAGE_REVIEW.md](LANGUAGE_REVIEW.md)에 수정 전후를 남겼습니다.

단어 예문은 그날 또는 해당 소분류의 문장을 먼저 표시하며, 다른 상황의 예문도 펼쳐 볼 수 있습니다. 비슷한 문장만 반복되지 않도록 문장 형태가 다른 예문을 우선 선택합니다.
