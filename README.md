# 콘서트 대비 일본어 노트

일본어를 처음 접하는 콘서트·팬미팅 관객을 위한 모바일 학습 앱입니다. 특정 아티스트나 팬덤에 한정하지 않고, 짧은 무대 멘트와 관객 지시를 이해하는 기초를 만듭니다. 한 달 안에 모든 콘서트 일본어를 습득하거나 실제 속도의 말을 이해할 수 있다고 보장하지 않습니다.

## 30일 필수 과정

하루 한 상황, 다섯 문장으로 총 150문장을 익힙니다. 날짜별 제목과 다섯 단계의 흐름에서 현재 위치를 표시합니다. 예를 들어 3일차는 신곡 소개 → 첫 공개 안내 → 담은 마음 → 가사에 주목 → 노래 시작으로 이어집니다. 실제 공연의 순서를 재현한 대본은 아닙니다.

- 첫인사·호응, 객석 위치·층수, 응원봉·손뼉·구호
- 신곡·앨범·가사·커버곡·안무·라이브 연주 소개
- MC 질문·답변, 관객 질문, 게임 규칙·제한 시간·힌트
- 촬영 허용·금지, 휴식·재개, 앙코르·다음 공연 소식·퇴장

[30일 전체 문장·단어와 흐름](SYLLABUS.md), [빠진 문장과 편입 문장의 전체 목록](CURRICULUM_CHANGES.md), [비중과 한계](COVERAGE.md)를 확인할 수 있습니다. 촬영 규칙과 일정 등은 학습용 예시이며, 실제 공연에서는 현장 공지와 직원 안내를 따릅니다.

## 학습 메뉴

1. 글자 첫걸음: 히라가나·가타카나, 소리 규칙, 공연 관련 예시와 루비 한자
2. 매일 공부해요: 30일 × 5문장과 그날의 단어·활용 예문
3. 문장으로 외워요: 인사·감사, 호응·곡 소개·진행, 소감·준비·팬에게 전하는 말
4. 단어로 익혀요: 문장과 연결한 단어와 활용 예문
5. 퀴즈로 확인해요: 일본어·한글 읽는 법을 보고 한국어 뜻을 고르는 2지선다

전체 라이브러리는 문장 카드 296개·단어 카드 284개입니다. 필수 과정은 중복 없는 150문장이고, 그 외 문장은 ‘선택 예문’으로 표시합니다. 운동·기타·겨울 여행 등 기존 소재는 선택 예문으로 보존합니다.

## 복습과 기록

- 1일차는 복습 없이 마무리합니다.
- 2~6일차는 전날 문장 중 3개, 7~30일차는 전날 2개와 더 이전 문장 1개를 복습합니다. 일부 문항은 해당 문장의 단어를 묻습니다.
- 오답 문장을 우선 선택하고, 날짜 잠금 없이 모든 날을 열 수 있습니다.
- 완료·오답 기록은 현재 브라우저에만 보관하며 기기 간 동기화되지 않습니다. 저장소가 차단되어도 학습은 가능합니다.
- 과정 개편으로 새 기록은 `concert-japanese-daily-v2`에 저장합니다. 이전 `aroha-daily-v1` 기록은 삭제하지 않으며, 바뀐 날짜에 이전 완료 표시를 그대로 적용하지 않습니다.

완료는 학습 진행 표시이며 숙달 판정이 아닙니다. 현재 복습은 모든 문장의 장기 기억을 보장하지 않고, 종합 듣기 평가도 제공하지 않습니다.

## 자료와 음성

실제 아티스트의 발언·일정·개인 취향을 인용하거나 단정하지 않는 학습용 예문입니다. 기존 자료에서 출발한 예문과 이번에 작성한 범용 공연 표현을 함께 제공합니다. 특정 소재는 선택 예문으로만 사용합니다.

일본어 발음 음성은 아직 없습니다. 한글 읽는 법은 보조 수단이며 일본어 발음을 정확히 재현하지 않습니다. 정답·오답·버튼 소리는 Web Audio 효과음입니다. 실제 청취를 위한 음성 훈련은 별도 개선 과제입니다.

## 실행·검증·배포

이 폴더에서 `python3 -m http.server 8001 --bind 127.0.0.1`을 실행합니다. 별도 설치·빌드·비밀키는 필요하지 않습니다. Google Fonts는 선택 사항이며 기본 폰트로도 동작합니다.

데이터 연결·보기·필수 범위 검증: `node tests/curriculum.test.cjs`

GitHub Pages는 `main` 브랜치의 `/(root)`를 게시 소스로 사용합니다. 변경을 `main`에 푸시한 뒤 Actions의 Pages 배포 결과를 확인합니다.
